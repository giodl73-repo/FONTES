## Boundary notes

MIT OCW course/listing pages are mapped as derived text. AIMA, AIMA Python,
Planning.Wiki, and Fast Downward are metadata-only pending exact reuse review.
OCW PDFs, lecture videos, problem-solving videos, programming assignments,
problem sets, solutions, exams, course downloads, textbook bodies, book PDFs,
exercises, figures, pseudocode PDFs, code repositories, notebooks, tests,
examples, generated docs, planner source, planner binaries, benchmarks, PDDL
examples, course-platform content, images, diagrams, and linked assets remain
boundary-checked.

## Decision support

Keep knowledge bases, inference rules, state spaces, search strategies,
heuristics, planning domains, problem instances, planner versions, plan traces,
and plan-validation results distinct. A generated plan or planner output is not
source evidence without PROOF-backed domain, problem, planner, and validation
provenance.
