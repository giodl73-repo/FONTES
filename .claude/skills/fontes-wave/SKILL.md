# fontes-wave

Use this skill to plan a multi-pulse FONTES wave.

## Checklist

1. Name the source family, downstream consumers, and source-custody objective.
2. Separate source discovery from fetch/cache execution.
3. Record license posture and fetch policy before any download.
4. Identify FLETCH registry, PROOF custody records, PEBBLE packs, and CROP views.
5. Name validation commands for every pulse.

## Guardrails

- Do not mirror online books by default.
- Treat assigned textbooks as metadata-only unless the license permits caching.
- Keep `.fletch\cache` out of git.
- Prefer source records and generated artifacts over downstream prose edits.
