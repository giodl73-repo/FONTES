## Boundary notes

PDFs, framework profiles, playbook pages, model-card examples, datasheet
templates, paper bodies, figures, benchmark datasets, benchmark outputs, model
outputs, result tables, generated benchmark pages, task YAMLs, evaluation
configs, repository code, docs, package artifacts, releases, images, diagrams,
and linked assets are not cached by this tranche.
