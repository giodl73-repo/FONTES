# 6.837 Computer Graphics Custody

## Source

MIT OpenCourseWare course page:
`https://ocw.mit.edu/courses/6-837-computer-graphics-fall-2012/`

## Current custody decision

6.837 is a game-engine support source for rendering and graphics. It anchors
curves, surfaces, transformations, hierarchical modeling, color, animation,
particle systems, collision detection, ray casting, ray tracing, acceleration
structures, shading, texture mapping, global illumination, rasterization,
graphics hardware, and computer games.

OCW-owned course pages, syllabus, calendar, assignment page prose, handout PDFs,
and course download page are mapped under MIT OCW CC BY-NC-SA 4.0. Starter
code, executables, platform bundles, model assets, and other code/resource
archives are local-cache only until downstream review decides what can be
indexed. Recommended textbooks remain metadata-only boundaries.
