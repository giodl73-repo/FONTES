# 6.801 Machine Vision Custody

## Source

MIT OpenCourseWare course page:
`https://ocw.mit.edu/courses/6-801-machine-vision-fall-2020/`

## Current custody decision

6.801 is a MIT AI/perception source map. OCW-owned course pages, syllabus,
lecture-note PDFs, and project instructions are eligible for `derived_text_allowed`
handling under the MIT OCW terms recorded in `sources\mit\ocw\TERMS.md`.

The course download page states that the downloadable package contains the same
content as the online course except audio/video materials. Assignments and exams
remain review-gated because the fetched pages did not expose structured resource
rows even though the syllabus lists problem sets and take-home quizzes.

## Fetch policy

| Source | Policy | Reason |
|---|---|---|
| Course, syllabus, lecture notes, project page | `derived_text_allowed` | OCW terms allow sharing/adaptation under CC BY-NC-SA 4.0. |
| Course download | `bundle_allowed` | OCW download package excludes audio/video materials per page text. |
| Assignments/exams | `license_review` | Pages were sparse in fetched output; resource-level inventory still needed. |
| External platforms/tools | `license_review` | OpenCV, AndroidStudio, MontiVision, Python/C++ tooling references are external. |
