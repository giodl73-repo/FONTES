# 18.086 Mathematical Methods for Engineers II Custody

## Source

MIT OpenCourseWare course page:
`https://ocw.mit.edu/courses/18-086-mathematical-methods-for-engineers-ii-spring-2006/`

## Current custody decision

18.086 is a PDE and numerical simulation support source for FONTES. It anchors
initial-value problems, wave/heat/convection equations, conservation laws,
Navier-Stokes framing, finite-difference accuracy and stability, CFL and Von
Neumann conditions, Fourier analysis of diffusion/dissipation/dispersion,
spectral methods, large sparse linear systems, finite differences, finite
elements, optimization, reordering, iterative methods, preconditioning, Krylov
methods, conjugate gradients, GMRES, multigrid, inverse problems, and
regularization.

OCW-owned course pages, syllabus, assignment page prose, homework and solution
PDFs, project page prose, sample project PDFs, and course download page are
mapped under MIT OCW CC BY-NC-SA 4.0. MATLAB support files, project ZIPs, video
media bytes, assigned textbooks, book pages, and external resources remain
local-cache or metadata-only boundaries.
