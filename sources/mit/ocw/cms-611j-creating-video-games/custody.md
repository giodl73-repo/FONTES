# CMS.611J / 6.073 Creating Video Games Custody

## Source

MIT OpenCourseWare course page:
`https://ocw.mit.edu/courses/cms-611j-creating-video-games-fall-2014/`

## Current custody decision

CMS.611J extends the CMS.608 analog-game source into digital game production. It
anchors small-team creative work, project management, iterative design across
gameplay/audio/visuals/fiction/programming, playtesting, focus testing, data
analysis, postmortems, user interface work, serious games, scope control, and
shipping/presentation practices.

OCW-owned course pages, syllabus text, instructor insights, project resources,
focus-testing resources, bug-reporting/project-management documents, and the
course download package are mapped under MIT OCW CC BY-NC-SA 4.0. Lecture videos
are local-cache only and stay out of git. Project 4 climate/humanitarian links,
external game links, YouTube thumbnails, student game builds, and third-party
tools are metadata or child-resource review boundaries unless separate source
records capture explicit terms.

knowledge: team formation, backlog/task management, game-engine onboarding,
