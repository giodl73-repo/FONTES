## Source

MIT OpenCourseWare course page:
`https://ocw.mit.edu/courses/11-127j-computer-games-and-simulations-for-education-and-exploration-spring-2015/`

## Current custody decision

11.127J / CMS.590J extends the game-design lane into educational games,
simulations, board-game and digital-game production, classroom implementation,
field testing, learning assessment, and project-based learning.

OCW-owned course pages, syllabus, calendar, assignments, instructor insights,
and the downloadable course package are mapped under MIT OCW CC BY-NC-SA 4.0.
The readings page is a citation boundary because it references commercial
texts, MIT Press books, and third-party articles. Student project examples, if
recovered through the course package or page graph, must be treated as project
metadata unless explicit reusable terms are captured.

## Portfolio relevance

This course supports games-design and educational-product repos by capturing
how to design games around learning goals, test whether users learn from a
game, document board/digital game designs, and connect prototype field testing
to assessment evidence.
