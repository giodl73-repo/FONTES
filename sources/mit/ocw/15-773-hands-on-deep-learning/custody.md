# 15.773 Hands-on Deep Learning Custody

## Source

MIT OpenCourseWare course page:
`https://ocw.mit.edu/courses/15-773-hands-on-deep-learning-spring-2024/`

## Current custody decision

15.773 is a MIT Sloan hands-on deep-learning source map. OCW-owned pages,
schedule metadata, syllabus text, and downloadable course package metadata are
eligible for FONTES extraction under MIT OCW terms.

The assigned textbook, public dataset sources, Hugging Face/Kaggle/Google
Dataset Search links, lecture media, and individual programming assignment
artifacts require resource-level review before bundling.

## Fetch policy

| Source | Policy | Reason |
|---|---|---|
| Course, syllabus, schedule | `derived_text_allowed` | OCW terms allow sharing/adaptation under CC BY-NC-SA 4.0. |
| Course download | `bundle_allowed` | OCW download package excludes audio/video materials per page text. |
| Video media | `local_cache_allowed` | Do not bundle media bytes. |
| Textbook and public dataset sources | `metadata_only` / `license_review` | External sources require their own terms. |
| Programming assignment artifacts | `license_review` | Individual notebooks/code/data need artifact inventory. |
