# CMS.300 Introduction to Videogame Studies Custody

## Source

MIT OpenCourseWare course page:
`https://ocw.mit.edu/courses/cms-300-introduction-to-videogame-studies-fall-2011/`

## Current custody decision

CMS.300 complements CMS.301 by anchoring the analytic and cultural side of the
game-design lane. It maps videogames as texts, game culture, narrative,
identity, player types, cybertexts, simulation, value systems, aesthetics,
violence, journalism, and game-analysis writing practice.

OCW-owned course pages, syllabus, lecture-note listing and PDFs, assignment
pages, game-analysis guidance, and course download package are mapped under MIT
OCW CC BY-NC-SA 4.0. The readings page is useful citation metadata but includes
commercial books, MIT Press books, journal articles, external PDFs, and web
links that require separate source records before any content reuse. Lab games,
student-selected games, and game assets are metadata-only boundaries.

## Portfolio relevance

CMS.300 provides downstream games-design repos with critical vocabulary and
analysis methods for interpreting games as cultural, social, educational, and
formal systems. It is especially useful for design reviews, values analysis,
game criticism, player-experience framing, and research-facing game mechanics
discussion.
