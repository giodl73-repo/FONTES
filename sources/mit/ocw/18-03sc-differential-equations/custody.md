# 18.03SC Differential Equations Custody

## Source

MIT OpenCourseWare course page:
`https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/`

## Current custody decision

18.03SC is a simulation mathematics and game physics support source for FONTES.
It anchors first-order ODEs, analytic/geometric/numerical solution approaches,
second-order systems, sinusoidal forcing, periodic response, Fourier series,
Laplace transforms, convolution, impulse response, first-order systems,
qualitative phase portraits, nonlinear systems, and linearization.

OCW-owned course pages, unit pages, course notes, problem sets, practice
problems, exams, solutions, and course download page are mapped under MIT OCW
CC BY-NC-SA 4.0. Lecture/problem-solving video media bytes, Java mathlets,
interactive applet assets, and illustrative images remain local-cache or
metadata-only boundaries.
