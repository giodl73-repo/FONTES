## Current custody decision

6.831 / 6.813 is a game UI and interaction support source for FONTES. It
anchors usability, learnability, visibility, error prevention, efficiency,
user-centered design, task analysis, UI architecture, layout, input/output,
user testing, controlled experiments, prototyping, graphic design,
accessibility, internationalization, animation, and mobile interfaces.

OCW-owned course pages, syllabus, calendar, lecture-note listing and PDFs,
assignment/project page prose, assignment/project PDFs, and course download page
are mapped under MIT OCW CC BY-NC-SA 4.0. Programming assignment ZIPs and any
code/resources are local-cache only until downstream review. Recommended
textbooks, graduate literature readings, and unavailable nanoquizzes remain
metadata-only or unavailable boundaries.
