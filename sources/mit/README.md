# MIT Sources

MIT is the first FONTES source family. The goal is complete source custody, not
blind mirroring.

## First pass policy

| Material | Default policy |
|---|---|
| OCW course landing pages | `local_cache_allowed` for metadata/page capture after robots and license review. |
| OCW readings tables | `derived_text_allowed` for the table text when covered by OCW terms. |
| Assigned commercial textbooks | `metadata_only` unless a separate open license is found. |
| Author-hosted free-to-read books | `metadata_only` or `license_review` unless download/redistribution terms are explicit. |
| Supplemental PDFs | `license_review` until each resource's rights statement is checked. |
