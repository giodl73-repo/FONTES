# MIT Sources

MIT is the first FONTES source family. The goal is complete source custody, not
blind mirroring.

## First pass policy

| Material | Default policy |
|---|---|
| OCW course landing pages | `derived_text_allowed` under OCW CC BY-NC-SA 4.0 terms, with attribution and noncommercial/share-alike constraints. |
| OCW readings tables | `derived_text_allowed` under OCW CC BY-NC-SA 4.0 terms. |
| OCW-owned downloadable files | `bundle_allowed` when the file is part of OCW and not separately restricted. |
| Assigned commercial textbooks | `metadata_only` unless a separate open license is found. |
| Author-hosted free-to-read books | `metadata_only` or `license_review` unless download/redistribution terms are explicit. |
| Supplemental PDFs | `license_review` until each resource's rights statement is checked. |

See [`ocw/TERMS.md`](ocw/TERMS.md) for the recorded OCW license source.
