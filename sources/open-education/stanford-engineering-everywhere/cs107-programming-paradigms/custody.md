# CS107 Programming Paradigms Custody

## Source

Stanford Engineering Everywhere course page:
`https://see.stanford.edu/Course/CS107`

## Current custody decision

CS107 is a CS/software source anchor for systems programming, memory models,
C/C++, assembly, concurrency, functional programming, and Python. SEE states
that, unless otherwise indicated, SEE content is CC BY-NC-SA 4.0 and includes
lecture videos, slides, reading lists, handouts, homework, quizzes,
examinations, and solution sets.

Non-video CS107 course materials are eligible for `bundle_allowed` handling.
Lecture videos are downloadable from SEE but should remain FLETCH cache objects,
not git content. Assignment code and data archives are mapped as SEE-distributed
course materials but should still receive child-resource review before any
derived package is promoted downstream.

## Fetch policy

| Source | Policy | Reason |
|---|---|---|
| Course page | `derived_text_allowed` | SEE course metadata, resource tables, assignments, and lecture-session metadata. |
| Syllabus/course information PDF | `bundle_allowed` | SEE-distributed PDF under family policy unless otherwise indicated. |
| All course materials ZIP | `bundle_allowed` | SEE offers non-video course materials as downloadable ZIP. |
| Section and programming assignments | `bundle_allowed` | SEE-distributed handouts, solutions, starter code, and data under family policy unless otherwise indicated. |
| Lecture videos | `local_cache_allowed` | Downloadable MP4s are allowed for local FLETCH cache, but large media bytes stay out of git. |
| Transcripts | `bundle_allowed` | SEE-distributed HTML/PDF transcript files under family policy unless otherwise indicated. |

## Portfolio relevance

CS107 anchors low-level programming concepts needed by tools-infra, coding-agent
context packs, game-engine reasoning, memory/cost models, concurrency
tradeoffs, and systems-level debugging.
