# Stanford Public Programming/Software Course Sites Custody

## Research question

Which Stanford public programming and software-development course-site source
identities should follow the robotics/autonomy Stanford slice?

## Current custody decision

This tranche anchors public Stanford programming/software course homepage
identities: CS106A, CS106B, CS107, CS110, CS111, CS193P, CS193X, and CS193A.
These are `metadata_only` source-identity rows until course-specific terms and
child resources are reviewed.

Some courses overlap with existing Stanford Engineering Everywhere custody. This
slice intentionally treats current public course homepages as separate
metadata-only discovery anchors; it does not change SEE bundle policy or promote
any current public-course child resource.

Course homepages can route FLETCH discovery and PROOF source identity. Notes,
slides, handouts, assignments, exams, projects, labs, code, datasets, software,
tools, APIs, videos, transcripts, readings, linked services, and third-party
assets remain boundary-checked and must not be cached or redistributed from this
row.
